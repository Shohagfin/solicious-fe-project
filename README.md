# Restaurant Website Template

A modern, responsive restaurant website template with multiple layout options.

## Features
- Multiple homepage layouts
- Responsive design with Bootstrap
- Menu presentation pages (grid, tabs, thumbnails)
- Online reservation system
- Event management pages
- Blog functionality
- Contact forms
- Revolution Slider integration
- Light and dark theme variants

## Technologies Used
- HTML5
- CSS3 (Bootstrap, Custom Animations)
- JavaScript/jQuery
- PHP (for forms)
- Revolution Slider

## Setup Instructions
1. Clone the repository
2. Configure your web server to point to the root directory
3. Update `email.php` and `reservation.php` with your email settings
4. Customize content in HTML files as needed

## File Structure
- `/css` - Stylesheets
- `/js` - JavaScript files
- `/fonts` - Icon and web fonts
- `/images` - Image assets
- `/HTML-light` - Light theme variant
- `/revolution` - Revolution Slider plugin
